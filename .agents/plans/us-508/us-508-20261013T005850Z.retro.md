# Retro proposals — us-508

Advisory, propose-only. Candidates validated by `validate_candidates.cjs` (R1–R3 accepted).

| ID | Severity | Category | Title | Proposed change |
|----|----------|----------|-------|-----------------|
| R1 | medium | memory | JSON-printing gate also prints a report path after the payload | Never `JSON.parse` the full stdout of a gate `--json --report` run; parse the `{…}` slice or split the runs. |
| R2 | medium | memory | cmd.exe eats `^` in git revision arguments | Pass git revisions containing `^` via `spawnSync` argv, never a shell/`execSync` string. |
| R3 | low | navigation-pointer | Full-tree skill fixtures are expensive; minimize copies | Reuse one copied skills fixture; build extra fixtures minimally (only the files a check reads). |

## Evidence

- R1: `test/test-check-workflows-global-root.js` — a combined `--json --report`
  run printed JSON plus `📝 Report saved to …`, breaking `JSON.parse(stdout)`.
- R2: scratch fresh-verify probe — `execSync('git show REV^:path')` on Windows ran
  through `cmd.exe`, consumed the caret, and injected the wrong revision.
- R3: two full-tree `fs.cpSync` copies of `.agents/skills` dominated the suite
  runtime (~30–60 s each on Windows).

None of these blocked delivery; all are recorded in `.ws/memory/`
(`2026-10-12-us508-check-workflows-resolver-tests.md`).
