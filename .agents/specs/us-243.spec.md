# Specification — Improve ws-spec-memo: hand off runtime ops to spec-memo ws-memo (keep setup here)

## Description

Keep **`ws-spec-memo`** in workflow-skills as the consumer **setup/bridge** for `specMemo.*` in `{sharedDir}/config.json` (import, hybrid MEMORY fallback, write-block hook interview, check/bootstrap). Day-to-day vault operations (search, get, forget, gc, promote formats, canvas, SSE, rank, vault sync/backup) belong to **`ws-memo`** from the [spec-memo](https://github.com/jpolvora/spec-memo) package — not duplicated here.

Touch points: `.agents/skills/ws-spec-memo/SKILL.md`, `references/INTEGRATION.md`, `references/MCP-TEMPLATE.json`, `scripts/check_spec_memo.cjs`, `evals/evals.json`, and brief alias notes in `.agents/skills/ws-shared/tools.md` (and/or self-learning/changelog pointers). Do not vendor `ws-memo` or `SURFACE.md` into this repo.

Agents finishing setup must be pointed at `/ws-memo` (or `{skillsRoot}/ws-memo/SKILL.md`) for runtime ops. Docs and optional health checks may warn when `ws-memo` is missing; they must not fail the Recommended disabled-vault path or invent a ninth MCP tool.

## Acceptance Criteria

- AC1: `references/INTEGRATION.md` states the two-skill split (`ws-spec-memo` = wiring/`specMemo.*`; runtime ops = `ws-memo`) and that `ws-spec-memo` does not own search/get/gc/promote/canvas/SSE/status/rank/backup/sync.
- AC2: `INTEGRATION.md` tells agents that after `specMemo.enabled: true` and MCP registration they must load `ws-memo` from the spec-memo package/clone (`{skillsRoot}/ws-memo` or copy from spec-memo `.agents/skills/ws-memo/`).
- AC3: `SKILL.md` includes a one-line runtime next step pointing at `/ws-memo` (spec-memo skill) after setup/check/bootstrap/import/disable paths without pasting an 8-tool MCP table.
- AC4: `references/MCP-TEMPLATE.json` keeps stdio `memo serve` / npx serve as default snippets and adds an optional comment pointing at spec-memo `ws-memo/references/MCP-TEMPLATE.json` for SSE/status ports `3000`/`3001` and canvas `4100`.
- AC5: When `specMemo.enabled` is explicit `true`, `check_spec_memo.cjs` reports (warn, exit 0) whether MCP `spec-memo` is expected and whether `{skillsRoot}/ws-memo/SKILL.md` exists; missing `ws-memo` does not fail the check.
- AC6: When `specMemo.enabled` is not explicit `true`, `check_spec_memo.cjs` exits 0 without requiring `ws-memo` or MCP registration.
- AC7: `tools.md` vault reroute notes (when `specMemo.enabled`) point trap/search follow-ups at `ws-memo` / `/ws-memo` instead of expanding `ws-spec-memo` into a command encyclopedia.
- AC8: `evals/evals.json` adds an eval that after setup the agent loads `ws-memo` for search/promote-style ops and does not invent a ninth MCP tool or duplicate SURFACE.md inside `ws-spec-memo`.
- AC9: Setup interview Recommended defaults still keep `specMemo.enabled: false` (no change that makes enable the Recommended first choice).
- AC10: No SURFACE.md (or other full vault command encyclopedia) is copied into `ws-spec-memo` skill docs.
