# Context — us-235 Step 5 to 6 deadlock

## Feature Boundary

This change unblocks `scoreAndRefine` pre-advance from Step 5 to Step 6 in messy-but-valid consumer repos. It covers alias classification, skip observations, `.runtime` residue, and state hashing.

It does not retune Step 5 scoring weights, does not auto-fix consumer format debt, and does not relax `knownDefect` caps for real failed verification.

## Implementation Decisions

1. **Required-alias filter:** Omit verification keys matching `/^_/`. Comment keys are documentation, not commands. Also stop publishing `_comment_mutationTest` in `config.json.example` (use a parent `_comment` or schema `description`).
2. **Missing-alias policy (chosen):** Keep fail-closed for *unobserved* required aliases. Add `aliasResult.skipReason` (`not-applicable` | `baseline-dirty` | `comment-key`). A skip counts as observed and does not set `knownDefect`. Pre-advance 6 still copies remaining scorer `errors[]` (truly missing aliases stay fatal).
3. **Why not option 1 (ignore missing-alias errors when score is 9):** That would let orch omit format with no audit trail. `skipReason` keeps the ledger honest.
4. **Why not option 3 (Step 5 require every alias before finish):** That contradicts today's 9/10 completeTen cap and would deadlock dirty-format consumers without a skip path.
5. **`.runtime` allowlist:** Allow `*.cjs`, `*.patch`, and `*.md` under `{us-dir}/.runtime/` so scoreAndRefine / sabotage helpers survive `update_state`. Keep rejecting unknown extensions.
6. **State hash:** Hash YAML frontmatter only so `## Gate history` body edits do not break `run.json.stateSha256`.
7. **`update_state finish --commit <sha>`:** Repeatable write of G2-code SHAs into `state.commits`.

## Deferred Ideas

- Auto-detect baseline-dirty format by diffing format-touching paths against `files_touched` (orch heuristic). Agents pass `skipReason` explicitly in this spec.
- Broader `.runtime` glob (`*`) or a nested `helpers/` directory.
- Canonical JSON snapshot as the hash target (frontmatter-only is enough).
- Removing `mutationTest` empty-string handling beyond "empty = skip" (already true).
