# Context — us-429 hub seed

## Feature Boundary

Issue 429 asks `ws-configure-project` to materialize a full `.ws/` tree, including managed `runtime/` and `templates/`, hub-local memory and changelog, and installer metadata. The shipped hub contract keeps managed trees in the skills install and places memory and changelog at `rules.memoryDir` / `rules.changelogFile`.

## Implementation Decisions

- Implement the current hub contract: seed missing hub `AGENTS.md`, `autoload.md`, `STACK.md`, and `.gitignore`; do not copy `runtime/` or `templates/` into the hub.
- Create `MEMORY.md`, `memory/`, and `CHANGELOG.md` only at the configured rule paths, on first use.
- Leave `installed-skills.json` and `skill-integrity-local.json` to the installer.

## Deferred Ideas

- Restoring managed `runtime/` and `templates/` copies under the consumer hub, as the issue text describes.
- Forcing memory and changelog files to live inside the hub root when config points at the repository root.
