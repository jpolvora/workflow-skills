Workflows

Choose the right workflow orchestrator for your task scope. Both share ws-shared/config.json and gates.md in dual-mode execution.

spec-to-pr

Standard FSM

Full multi-stage pipeline (Steps 0–9)

A comprehensive Finite State Machine orchestrator designed for end-to-end software lifecycle delivery from initial spec brainstorming down to PR shipping.

Pipeline Execution Steps:
  • Collaborative Spec Brainstorming (Step 0)
  • Architectural Review & Interview (Steps 1–2)
  • DAG Task Decomposition (Step 3)
  • Implement, verify & local code review (Steps 4–6)
  • Pre-PR testing, shipping & ws-goal-fix-pr (Steps 7–9)

spec-to-pr-lite

Lite FSM

Fast sequential pipeline (Steps 0–5)

A streamlined alternative designed to run planning, sequential coding, code review, and shipping in a rapid direct feedback loop.

Pipeline Execution Steps:
  • Planning & brainstorm from existing spec
  • Direct sequential coding (no complex DAG required)
  • Quick local code review & automatic fix cycles
  • Fast consolidation & PR delivery
  • Zero setup/config duplication in dual-mode

ws-multi-spec

Smart Multi-Spec Orchestrator

Sequential multi-spec queue execution with Smart Flow Auto-Detection

An intelligent orchestrator that processes a queue of feature specs sequentially. Automatically analyzes each spec's complexity (tasks, files, layers) to dynamically choose the optimal execution pipeline (full spec-to-pr or fast spec-to-pr-lite).

Key Smart Capabilities:
  • Smart Flow Auto-Detection: Auto-routes low-complexity specs to spec-to-pr-lite and complex specs to full spec-to-pr
  • Already-Implemented Probe: Probes previous PRs/commits to skip completed specs
  • Unified State Persistence: Tracks multi-spec execution status under {plansDir}/ws-multi-spec/
  • Interactive Failure Recovery: Pauses with clear user-gate options (Resume, Skip, Abort) on worker failure

Frequently Asked Questions

Everything you need to know about Workflow Skills, FSM execution engine, quality gates, and agent harness compatibility.

Workflow Skills is an open-source, agent- and IDE-neutral skill hub and Finite State Machine (FSM) framework. It equips AI coding assistants (Cursor, Windsurf, OpenCode, Claude Code, Gemini CLI, etc.) with structured software engineering workflows, quality gates, automated testing, and SCM PR delivery.

Instead of relying on free-form prompt engineering that leads to scope creep or unverified code, Workflow Skills enforces structured multi-step pipelines (Steps 0–9) where each phase calls specialized, single-responsibility skills.

The choice depends on task complexity and scope:

  • Standard (ws-spec-to-pr): A comprehensive 10-step pipeline (Steps 0–9). Includes deep architectural planning, interactive plan audit interviews, JSON DAG task graph decomposition, isolated subagent task execution, 2-phase local code review, pre-PR automated testing, and autonomous PR thread fixing.
  • Lite (ws-spec-to-pr-lite): A streamlined 6-step pipeline (Steps 0–5). Designed for direct sequential coding without complex DAG generation overhead, offering rapid feature delivery while maintaining code review and PR shipping gates.

ws-multi-spec is a sequential smart multi-spec batch orchestrator. It indexes all feature specifications under specs/, runs ws-classify-complexity on each spec to dynamically select between Standard or Lite pipeline execution, and processes them one by one.

It maintains state persistence under {plansDir}/ws-multi-spec/ (allowing safe session pauses/resumes), skips specs with already-merged PRs, and presents structured user-gate choices if a spec encounters an issue.

No! Workflow Skills maintains a strict separation between managed skill files and consumer-owned project data.

Files located under .agents/skills/ws-shared/ — including config.json, STACK.md, MEMORY.md, memory entries, and CHANGELOG.md — are strictly preserved during all updates and uninstalls. Only managed SKILL.md definitions and skill scripts are updated from canonical upstream releases.

Workflow Skills includes multiple layers of automated defense:

  • ws-senior-developer: Delivery gate enforcing surgical diff footprints, anti-reinvention checks, and pre-ship verification proof.
  • ws-fable-judge: Adversarial audit engine performing diff-grounded verification to detect 4 classic AI code frauds (weakened unit tests, false verification claims, unauthorized side effects, and scope creep).
  • ws-secrets-leak-review: Pre-PR scanner checking diffs for hardcoded API tokens, private keys, passwords, and sensitive credentials.

Workflow Skills is 100% harness-neutral and portable. Shipped skills run in any consumer environment capable of reading standard markdown skill files under .agents/skills/.

It supports Cursor, Windsurf, OpenCode, Claude Code, Gemini CLI, VS Code agent extensions, and custom AI agent harnesses without vendor lock-in or host-specific coupling.

You can run ws-configure-project or edit .agents/skills/ws-shared/config.json directly. Key configurable options include:

  • plans.dir: Target folder for workflow plans and execution artifacts (default: .agents/plans).
  • providers.scm: Active SCM provider (github via gh CLI, azure-devops via ADO PAT, or local).
  • rules.stackFile: Path to project technology stack guidance (default: .agents/skills/ws-shared/STACK.md).
  • testRunner & buildCommands: Automated verification and test execution commands.
