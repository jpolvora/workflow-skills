## Narration script

[ON SCREEN: you, full frame. Smile, then speak.]

Welcome. From Spec to Delivery. I am glad you are here.

[PAUSE]

If you use an AI coding agent, you already know the good part. You describe what you want, and code appears, fast. And you also know the hard part. [PAUSE] Did the agent build the right thing? Did it test it? Did it quietly change three other files? And when the pull request gets reviewed, who fixes the comments: you, at midnight, by hand?

This course is the fix for that. [PAUSE]

Workflow Skills is a free, open set of agent skills that takes one idea, written as a clear spec, and carries it all the way to a reviewed, merged pull request. The spec is the contract. Everything else, the plan, the code, the review, the tests, is derived from that contract, step by step, with a quality score that the agent cannot fake.

Here is what makes it different, in one breath. [PAUSE] One, it works with any coding agent, because skills are plain Markdown plus small Node scripts. Two, the same process runs on GitHub and on Azure DevOps, with the same steps. And three, nothing ships on the agent's word alone. Every claim gets checked.

[ON SCREEN: switch to the playlist page for five seconds, then back to you.]

Here is how the course flows. We start with the idea and the install. Then you write your first spec. Then we run the full pipeline, step by step, and I will show you the fast lite pipeline too, and how to choose. After that, the quality gates, shipping, and fixing review comments until there are zero left. Then we scale up: many specs, memory, a living wiki, and the advanced modes, including fully unattended runs. And we finish with a capstone, one real feature, from an empty spec to a merged pull request, start to finish.

You do not need a specific editor, and you do not need to be an expert. If you can run a terminal command and read a Markdown file, you can do everything in this course.

[PAUSE]

One promise before we start. Every command I show is real, and every step name is the exact name the tool uses today. No slides with fake screenshots. When something can fail, I will show you the failure and the fix, because that is where the learning is.

So. [PAUSE] If you are ready to stop prompting and hoping, and start specifying and verifying, you are in the right place.

Like the video if this sounds like your workflow, subscribe so you do not miss the pipeline chapters, and let us start with Chapter One: what Workflow Skills actually is, and why the spec comes first.
